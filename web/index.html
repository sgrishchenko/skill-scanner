        About GitHub access

        Public repositories work without credentials, within GitHub’s API limits. For higher limits, set GITHUB_TOKEN before starting the app. The token stays on this machine.

        Organization scans make at least two requests per repository, so set a token for larger organizations. Very large repositories must be scanned individually.

        One scan runs at a time. Closing this page discards its results; a running scan finishes in the background.
